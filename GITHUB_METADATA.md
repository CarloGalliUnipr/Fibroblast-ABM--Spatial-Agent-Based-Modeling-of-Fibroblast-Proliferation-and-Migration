## Suggested release description
This first public release provides the NetLogo implementation of a spatial agent-based model of human gingival fibroblast proliferation and migration, together with model documentation, parameter definitions, an ODD protocol, reproducibility guidance, and Python scripts for post-simulation logistic analysis. The model includes treatment-specific proliferation parameters, stochastic 24 ± 5 h division thresholds, passage-dependent senescence, short-range contact inhibition, paracrine stimulation, local nutrient depletion, collision avoidance, and passage- and crowding-dependent migration.

## Suggested manuscript-oriented software description
The Fibroblast ABM is a spatially explicit, stochastic agent-based model implemented in NetLogo to investigate the coupled effects of proliferation, migration, replicative age, local cell density, paracrine support, and nutrient availability on fibroblast population dynamics. Individual fibroblasts are represented as autonomous agents in a two-dimensional continuous spatial domain. Population-level growth is not imposed through a logistic carrying-capacity term; instead, growth saturation emerges from local biological and spatial constraints. The repository includes the simulation source code, model equations and assumptions, parameter documentation, ODD-style model specification, reproducibility guidance, and Python routines for analysis of simulation outputs.

## Suggested Zenodo description
This repository contains a NetLogo-based spatial agent-based model of human gingival fibroblast proliferation and migration. The model represents individual fibroblasts as autonomous agents whose proliferation is regulated by treatment-specific baseline growth propensity, serum availability, stochastic cell-cycle timing, replicative passage, local contact inhibition, paracrine support, and patch-level nutrient availability. Migration follows a random-walk process modulated by passage and local crowding, with collision avoidance and bounded spatial movement. The repository includes source code, detailed model documentation, an ODD protocol, parameter definitions, reproducibility guidance, and Python analysis scripts for fitting emergent population growth curves.
